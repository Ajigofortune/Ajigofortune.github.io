Who Owes Me (debt tracker app)

What I built

An installable app for small businesses to record who owes them money. It shows what is overdue or due soon, sends a polite WhatsApp reminder in one tap, records part-payments, adds due dates to the phone calendar, and has a PIN lock. Records stay on the user's phone and it works offline.

What it shows

Building a real tool for a real Nigerian problem with JavaScript, saving data on the device, and making a website installable like an app. I built it with AI tools while learning how the code works.

Calabar Roast (interactive coffee menu)

What I built

A mobile-friendly menu for a concept coffee house. Visitors switch between hot, cold and food categories, search the menu, add items to an order basket with quantities and a live total, and send the order on WhatsApp. It has automatic light and dark mode.

What it shows

Interactive page logic in JavaScript (filtering, searching, a basket that adds up and is remembered on the device) and a clean, mobile-first design. It is a concept project, not a real cafe. The photo is from Unsplash.
